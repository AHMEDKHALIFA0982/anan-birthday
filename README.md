# Anan Birthday Website 🎂

A funny, friendly birthday website made for Anan.

## How to run

Just double-click `index.html`.

For the smoothest result, you can also use VS Code with the **Live Server** extension.

## Add your own photos

Put these files inside the `assets` folder:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`

The website will automatically use them.

If they are not present, colorful placeholders are shown instead.

## Music

The website uses `assets/birthday-music.mp3`, created from **1:50 to 2:20** of the uploaded song.

The 30-second clip loops in the background and starts after clicking **"Open at your own risk"**. The Music ON/OFF button pauses and resumes it.

## Customize the message

Open `index.html` and search for:

`Happy Birthday, Anan!`

You can change the birthday message, photo captions, funny statistics, or any other text.

## Main files

- `index.html`
- `style.css`
- `script.js`
- `assets/`

Have fun 🎉
